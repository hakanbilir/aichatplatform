## 2025-05-20 - [Explicit Action States]
**Learning:** Users often click disabled-looking buttons to see why they don't work. However, keeping the "Send" button enabled but non-functional when the input is empty causes frustration ("clicking nothing").
**Action:** explicitly disable the primary action button when prerequisite input (empty text) is missing, but consider adding a tooltip explaining *why* if the reason isn't obvious (though for chat, empty input is self-explanatory).
