# AI Chat Platform

## Quickstart

```bash
bun install --frozen-lockfile
bun run quality
```

## Docs

Generate `DeveloperFollowMe.md`:

```bash
npm run docs:devfollowme
```

## Common Commands

```bash
bun run lint
bun run typecheck
bun run test
bun run build
bun run quality
bun run repair:ai
bun run security
```
